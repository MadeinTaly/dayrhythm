Why

Zero config works
Drop the tag in and you get a valid on/off day.
One JSON config
Models, presets, messages, classes and endpoints in one object.
Daily or weekly
A day is a plain array. A week adds carry-over, saved days and copy-to.
Pure core
DOM-free time functions for a Node server, with shared test vectors for ports.
Accessible
Keyboard handles, native dialogs, live announcements, reduced motion, forced colors.
Styled your way
Themes, CSS variables, ::part() and per-part classes for Tailwind.
